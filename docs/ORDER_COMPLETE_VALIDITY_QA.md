# 주문 완료 유효기간 표시 — #138 보완 3번

## 기준과 원인

- [#138 본문 5번](https://github.com/adapterz/wku-iksan-store-BE/issues/138)은 모든 교환권을 1년 공통 정책으로 명시한다.
- [보완 목록 3번](https://github.com/adapterz/wku-iksan-store-BE/issues/138#issuecomment-5777233026)은 단건과 그룹 주문 완료 화면의 표시 기준 차이를 다룬다.
- 확인 기준: FE develop `9434f88`, BE develop `4996b64`.
- 단건 조회의 `product.validPeriod`는 현재 상품의 `valid_period` 자유입력 문구다. 발급 교환권의 만료일 스냅샷이 아니다.
- 그룹 조회에는 해당 문구가 없고, 기존 완료 화면은 365일로 대체했다. 따라서 상품에 90일이 입력되면 단건은 90일, 그룹은 365일로 표시됐다.

## 보완

완료 화면은 주문 경로·상품 종류·수량·상품 문구와 무관하게 **발급일로부터 1년 이내에 사용 가능**으로 안내한다. 초기 HTML과 JS 렌더링 문구를 맞추고 `1년` 강조를 유지한다.

1년을 365일로 환산하거나 새 만료일을 계산하지 않는다. 향후 상품별 기간 정책이 도입되면 발급 시점의 기간/만료일을 어떻게 보존할지부터 별도로 설계해야 한다.

### 변경하지 않는 부분

- BE/API 명세·ERD·DB·마이그레이션 및 운영 상품 데이터
- 상품 상세페이지의 `validPeriod` 표시와 Aon 담당 상품 데이터 입력
- 실제 교환권 만료일 계산·만료 후 사용 차단
- 합계 표시 보완 PR #115 및 계정 전환 처리

이번 변경은 **기존 정책의 화면 안내 통일**이며, 만료 기능을 구현하거나 검증했다는 의미가 아니다.

## 검증 — 2026-09-30

- `node --test tests/order-complete-validity.test.cjs`: 신규 10개 통과
- `npm test`: 기존 125개 + 신규 10개, 총 **135개 통과**
- 단건의 90일·1년·빈 값·null·누락, 상품 1종/여러 종 그룹, 반복 렌더링, 기간 강조, 초기 HTML 일치 확인
- `git diff --check`: 통과
- PR #115의 제품 코드 패치를 현재 변경 위에 `git apply --check`로 검사: 충돌 없음. 실제 적용·통합 테스트는 하지 않았다.

실제 브라우저·BE 연동 및 운영 배포 검증은 수행하지 않았다. 자동 테스트는 실제 렌더러와 DOM 대역을 사용한다.

## 수동 확인 방법

1. 본인 소유의 기존 단건 주문 완료 화면에서 `발급일로부터 1년 이내에 사용 가능` 및 `1년` 강조를 확인한다.
2. 상품 1종 여러 개 주문과 여러 상품 주문 그룹에서도 동일한 문구인지 확인한다.
3. 로컬 테스트 상품의 기존 문구가 90일이거나 비어 있어도 완료 안내가 달라지지 않는지 확인한다. 운영 상품은 검증 목적으로 수정하지 않는다.
4. 상품 카드·합계·홈/선물함 버튼 및 계정 전환 시 이전 주문 숨김 동작이 유지되는지 확인한다.
