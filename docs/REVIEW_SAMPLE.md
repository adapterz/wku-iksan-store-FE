# 리뷰 페이지 로컬 샘플

기존 FE develop(728393e)의 430px 모바일 레이아웃, 공통 글꼴과 상품 이미지를 재사용한 독립 샘플입니다.
브랜치: prototype/review-pages. 기존 product.html, giftbox.html, 공통 JS는 변경하지 않았습니다.

## 확인할 흐름

- 상품 후기: 상품 선택, 실제 평균 별점·후기 수, 최신/별점 정렬, 5개씩 더 보기, 빈 목록.
- 받은 선물: 사용 완료 + 미작성은 작성 가능, 기존 후기는 수정, 사용 전 선물은 작성 불가.
- 내 후기: 본인 후기 조회, 별점/본문 수정, 삭제 확인.
- 작성 팝업: 1~5점, 공백 제외가 아닌 앞뒤 공백 제거 후 1~1,000 Unicode 글자, 개인정보 안내.
- 비로그인: 공개 후기만 조회 가능. 작성/내역은 로그인 필요.
- 작성 권한과 중복 검사는 실제 BE API에서 다시 확인합니다. 후기·인증 응답을 브라우저 스토리지에 저장하지 않습니다.
- 사진 업로드, 신고/관리자 숨김 UI, 좋아요는 이번 샘플 범위 밖입니다.
- 상단 상품 선택과 세 개 탭은 검토를 쉽게 하기 위한 샘플용 진입점입니다. 실제 FE 적용 시 상품 상세/선물함/마이페이지에 분리 연결합니다.

## 로컬 실행

Node.js 및 리뷰 구현 브랜치(feature/reviews-api)의 BE 의존성, 로컬 MySQL 8.0.16+가 필요합니다.
아래 경로는 자신의 체크아웃과 로컬 DB 환경 파일 위치로 지정합니다. 환경 파일을 커밋하지 마세요.

```powershell
$env:REVIEW_BE_ROOT = 'E:\notion\worktrees\wku-be-reviews'
$env:REVIEW_DB_ENV_FILE = 'C:\path\to\local-db.env'
node scripts/preview-reviews.cjs
```

http://127.0.0.1:8088/review-sample.html

- 상단의 IKSAN 문구와 별도 로그인·로그아웃 버튼은 제거했습니다. 비로그인 상태에서 **받은 선물/내 후기 → 샘플 계정으로 체험하기**를 선택하면 로컬에서만 Ethan 예시 계정을 사용합니다. 실제 회원 비밀번호는 필요 없습니다.
- 로컬 환경 파일에서는 DB_HOST/PORT/USER/PASSWORD만 읽고, DB_NAME은 사용하지 않습니다.
- review_preview_랜덤값 DB를 새로 생성해 예시 상품/사용완료 선물/후기를 채웁니다.
- DB 접속은 localhost 계열만 허용하며, 웹서버는 127.0.0.1에만 바인딩합니다.
- 샘플 로그인 엔드포인트는 이 로컬 실행기에만 존재합니다. 운영 배포에 포함하면 안 됩니다.
- Ctrl+C 정상 종료 시 해당 임시 DB를 제거합니다. 강제 프로세스 종료 시 임시 DB가 남을 수 있습니다.
- 기존 로컬 DB, 운영 DB, Wiki, GitHub 이슈/PR은 변경하지 않습니다.
- 현재 샘플 상품은 76~78번 3개이며, 상품·후기 내용은 기능 검증용 예시입니다.

## 확인

```powershell
node --check public/js/review-sample.js
node scripts/test-review-preview.cjs
```

브라우저에서는 등록/수정과 입력값 복원, 비로그인 안내, 작성 버튼 상태를 확인했습니다.
API 검증 스크립트는 샘플 서버가 켜져 있을 때 실행하며, 본인이 만든 테스트 후기만 삭제합니다.

- 기존 공통 CSS/JS, 상품 상세, 선물함, 마이페이지는 변경하지 않습니다. 실제 화면 연결 전 변경할 파일과 담당 범위를 조율합니다.
