# 주문 완료 합계 표시 — #138 보완 5번

관련: [보완 목록 5번](https://github.com/adapterz/wku-iksan-store-BE/issues/138#issuecomment-5793343420)

## 변경 범위

- FE develop `9434f88` 기준. #107 계정 전환 보완과 #110·#111 수정이 포함된 상태에서 재검증했다.
- 단건 및 상품 1종 주문 그룹에도 기존 합계 영역을 표시한다.
- 예: `총 1종 · 교환권 3개 · 13,500원`.
- 여러 상품 주문의 기존 표시 및 스타일은 유지한다.
- 주문 총액은 API의 `totalPrice`를 사용한다. 현재 상품 가격으로 다시 계산하지 않는다.
- 총액이 없는 응답은 기존 방식대로 상품 종류·수량만 표시한다. 0원으로 임의 대체하지 않는다.
- 상품이 없는 응답은 합계 영역을 숨기고 이전 요약 문구도 지운다.

FE 표시 조건·주석·회귀 테스트만 변경한다. BE/API/DB/마이그레이션, 결제 계산, 유효기간 정책 및 계정 전환 로직은 변경하지 않는다.

## 수동 확인 방법

1. 테스트 계정 소유의 기존 단건 주문 `/complete?orderId=...`를 열어 카드 아래 상품 종류·교환권 수량·총액이 표시되는지 확인한다.
2. 상품 1종을 여러 개 주문한 `/complete?orderGroupId=...`에서 API 총수량·총액과 화면 값이 일치하는지 확인한다.
3. 여러 상품 주문의 모든 카드와 기존 합계가 유지되는지 확인한다.
4. 모바일 폭에서 합계 줄이 잘리거나 하단 버튼과 겹치지 않는지 확인한다.
5. 다른 계정으로 전환하거나 로그인 만료 시 이전 완료 화면을 숨기는 #107 동작이 유지되는지 확인한다.

운영 주문 생성·운영 데이터 변경은 하지 않았다. 실제 브라우저/BE 연동 수동 확인은 별도로 필요하다.
